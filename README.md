# ProblemLab

Application Android (Kotlin, Jetpack Compose) de signalement d'observations
et de propositions, avec un Agent IA. Backend : Supabase.

## Configuration

Créer un fichier `local.properties` à la racine du projet et y ajouter :

SUPABASE_URL=https://ton-projet.supabase.co
SUPABASE_KEY=ta_cle_publishable

## Lancer le projet

Ouvrir le dossier dans Android Studio, synchroniser Gradle, puis lancer sur un émulateur.
